## 4. Technical Debt & Deferred Items

The following items were identified and documented during the milestone:

1. **Modified Autocorrelation-Corrected Mann-Kendall (Hamed & Rao)**
   - *Status:* Deferred by decision in Phase 2.
   - *Rationale:* Standard Mann-Kendall severely inflates false-positive rates under positive autocorrelation ($AR(1) > 0$). OLS + Newey-West HAC serves as the primary inferential estimator with Theil-Sen as an outlier point diagnostic. Hamed & Rao modified MK can be evaluated in future milestones after comprehensive simulation testing.
   - *Severity:* Low.

2. **Live NASA Earthdata DAAC Authentication**
   - *Status:* Environment-dependent.
   - *Rationale:* Live fetching requires user-supplied `EARTHDATA_TOKEN` in the environment. Offline cache and curated demonstration samples operate with 100% fidelity without network access.
   - *Severity:* Low.

3. **High-Density Raster Tile Layer for Dense Grids**
   - *Status:* Architecture evolutionary path.
   - *Rationale:* Current MapLibre CanvasSource and GeoJSON polygon rendering gracefully handles up to 10,000 cells (with server-side decimation). Global high-resolution meshes (e.g., 0.1° IMERG global grid with $>6\text{M}$ cells) will benefit from Cloud-Optimized GeoTIFF (COG) or custom WebGL shader tiles in future phases.
   - *Severity:* Low.

4. **Arbitrary Multi-Polygon Geometry Intersection Optimization**
   - *Status:* Monitored.
   - *Rationale:* Complex multi-polygons crossing the antimeridian are split and computed via Shapely + pyproj.Geod. While fast for typical bounding boxes and subcontinents, extremely intricate polygons ($>10,000$ vertices) could be accelerated with spatial indexing (R-tree) in a future optimization pass.
   - *Severity:* Very Low.

## 5. Scientific Guardrails Audit

All non-negotiable rules defined in `AGENTS.md` and `docs/SCIENTIFIC_RULES.md` were strictly upheld:

- [x] **No Causal Attribution:** All evidence summaries emphasize observational trend detection; causal claims are explicitly prohibited and caveated.
- [x] **No False Equivalence:** Comparing one significant region with one non-significant region is disallowed; paired contrast tests $D_t = Y_{A,t} - Y_{B,t}$ directly.
- [x] **No Manufacturing Opposites:** Inconclusive outcomes are reported truthfully with semantic badges and explicit caveats.
- [x] **No Silent Temporal Infill:** Missing calendar months are never interpolated or replaced with zeros.
- [x] **Symmetric Diverging Visuals:** Zero-centred palettes (`RdBu`/`BrBG`) with frozen symmetric domain $[-\max\|\beta\|, +\max\|\beta\|]$.
- [x] **Explicit Multiplicity Disclosure:** Any candidate chosen after inspecting the screening map is marked `exploratory_map_selected`.
