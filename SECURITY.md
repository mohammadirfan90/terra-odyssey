# Security Policy

## Supported Versions

The following versions of Terra Odyssey are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of Terra Odyssey and user data seriously. If you discover a security vulnerability or credential leak risk:

1. **Do Not Open a Public Issue**: Please do not disclose vulnerabilities through public GitHub issues or discussions.
2. **Submit via GitHub Private Vulnerability Reporting**: Use the **Security** tab on GitHub and click **Report a vulnerability**.
3. **Information to Include**:
   - Description of the vulnerability.
   - Exact steps or script to reproduce the issue.
   - Potential impact and affected components.
4. **Response Timeline**:
   - We will acknowledge receipt within 48 hours.
   - We will provide an assessment and timeline for a patch.
