# Stitch-to-code handoff checklist

- [ ] Screen purpose and primary user action are written in `docs/UX_SPEC.md`.
- [ ] Approved layout is captured as a reference image or Stitch export.
- [ ] Components map to real frontend components, not one giant generated page.
- [ ] All chart/map numbers come from typed result fixtures or the API.
- [ ] Empty, loading, error, unavailable, and inconclusive states exist.
- [ ] Units, period, source/version, coverage, and uncertainty are visible.
- [ ] Text/table alternatives exist for map and chart information.
- [ ] No generated copy makes causal claims or invents NASA measurements.
- [ ] Color tokens and interaction behavior are copied into the code design
  system, not left only inside Stitch.
- [ ] Frontend tests cover region selection, linked updates, and no-result state.
